01 / SIKANG LAB

关于本站

Sikang Lab 是我的个人技术实践站。内容来自日常开发和项目实践，主题包括后端服务、自动化工具、AI Agent、前端实现和工程协作。

这里不放教育经历、论文或包装过的技能清单。我更愿意记录一个问题为什么出现、方案如何选择、实施过程中踩过哪些坑，以及最后留下了什么可复用的结论。

Java 后端Python 自动化AI Agent全栈开发工程实践生活记录

02 / FOCUS

我的关注

我是郭同学，一名全栈开发者。目前主要关注 Java 与 Python 工程、Web 应用、AI Agent 的实际落地，以及开发流程中的效率问题。

比起追逐概念，我更在意技术能否稳定地解决问题：代码是否容易维护，工具是否真正节省时间，方案在离开演示环境后是否依然可靠。

这个网站也是我的工作台。它帮助我梳理思路、检验理解，并为下一次遇到类似问题保留清晰的参考。

03 / NOTES

写在后面

本站不会为了更新而更新。文章可以不多，但每篇内容都应该有明确的问题背景、可验证的过程和尽可能准确的结论。旧内容发现问题后也会继续修正。

如果某篇记录帮到了你，或者你发现其中有遗漏和错误，欢迎通过 GitHub 提交 Issue 或参与修改。技术内容在交流和校正中会变得更有价值。
