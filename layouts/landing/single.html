{{ if $zh }}

Sikang Lab 是我的个人技术实践站。内容来自日常开发和项目实践，主题包括后端服务、自动化工具、AI Agent、前端实现和工程协作。

{{ else }}

Sikang Lab is my personal engineering site. Its content comes from daily development and project work, covering backend services, automation tools, AI Agents, frontend implementation, and engineering collaboration.

Instead of showcasing credentials or polished skill lists, I document why a problem appeared, how I chose a solution, what went wrong during implementation, and which conclusions are reusable.

02 / FOCUS

{{ if $zh }}我的关注{{ else }}My Focus{{ end }}

{{ if $zh }}

我是郭同学，一名全栈开发者。目前主要关注 Java 与 Python 工程、Web 应用、AI Agent 的实际落地，以及开发流程中的效率问题。

比起追逐概念，我更在意技术能否稳定地解决问题：代码是否容易维护，工具是否真正节省时间，方案在离开演示环境后是否依然可靠。

这个网站也是我的工作台。它帮助我梳理思路、检验理解，并为下一次遇到类似问题保留清晰的参考。

{{ else }}

I'm Sikang, a full-stack developer focused on Java and Python engineering, web applications, practical AI Agent systems, and more efficient development workflows.

I care less about chasing concepts than whether technology solves problems reliably: whether code is maintainable, tools save real time, and solutions still work outside a demo.

This website is also my workbench. It helps me organize ideas, test my understanding, and leave a clear reference for the next similar problem.
