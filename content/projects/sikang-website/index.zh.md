Sikang Lab 是我的个人技术实践站，用来持续整理 AI Agent、后端开发、自动化工具与工程思考。

## 项目定位

- 使用 Hugo 生成中英双语静态页面。
- 通过 GitHub Actions 自动构建并部署到 GitHub Pages。
- 使用 Pagefind 提供站内搜索，并针对桌面与移动端进行响应式适配。
